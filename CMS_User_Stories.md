# Conference Management System (CMS)
## User Stories

### Actors
- Guest (Public User)
- Author
- Referee / Reviewer
- Editor
- Administrator
- Attendee
- External Payment Service
- Email Notification System

---

## User Stories

### Registration & Authentication

**US-1 – User Registration**  
As a **guest**, I want to register with a unique email and secure password so that I can access CMS features.

**US-2 – User Login**  
As a **registered user**, I want to log in using my username and password so that I can access my personal dashboard.

**US-3 – Change Password**  
As a **registered user**, I want to change my password so that I can keep my account secure.

---

### Paper Submission (Author)

**US-4 – Submit Paper**  
As an **author**, I want to submit a paper with metadata and a manuscript file so that it can be reviewed.

**US-5 – Save Draft Submission**  
As an **author**, I want to save my paper submission at any stage so that I can complete it later.

---

### Referee Assignment (Editor)

**US-6 – Assign Referees**  
As an **editor**, I want to assign up to three referees to each submitted paper so that it can be properly reviewed.

**US-7 – Confirm Referee Assignment**  
As a **system**, I want to track referee acceptances so that no paper has more than three reviewers and no referee has more than five papers.

---

### Paper Review & Decision

**US-8 – Review Paper**  
As a **referee**, I want to access assigned papers and submit a completed review form so that the editor can evaluate the paper.

**US-9 – Make Acceptance Decision**  
As an **editor**, I want to make a final accept/reject decision once all reviews are submitted so that authors can be notified.

---

### Scheduling

**US-10 – Generate Schedule**  
As an **administrator**, I want the system to automatically generate a conference schedule so that accepted papers are assigned times and rooms.

**US-11 – Edit Schedule**  
As an **editor**, I want to modify the generated schedule so that conflicts and issues can be resolved.

---

### Conference Registration & Payment

**US-12 – Register for Conference**  
As an **attendee**, I want to pay the registration fee online so that I can attend the conference and receive a ticket.
