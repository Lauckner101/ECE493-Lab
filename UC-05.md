# UC-05: Save Paper Submission Draft

## Use Case (Cockburn Style)

**Goal in Context**  
Allow an author to save a partially completed paper submission so it can be completed later.

**Scope**  
Conference Management System (CMS)

**Level**  
User Goal

**Primary Actor**  
Author

**Secondary Actors**  
Database System

**Trigger**  
Author selects the **Save** option while filling out the paper submission form.

### Success End Condition
- A draft of the paper submission is successfully saved and retrievable.

### Failed End Condition
- The draft is not saved.

### Preconditions
- The author is registered in the CMS.
- The author is logged into the CMS.
- The author has started a paper submission.

### Main Success Scenario
1. The author enters partial paper information.
2. The author selects the **Save** option.
3. The system validates entered information.
4. The system stores the submission as a draft.
5. The system confirms that the draft has been saved.

### Extensions
- **3a**: Entered information is invalid.  
  - The system displays a validation error and does not save the draft.
- **2a**: No information is entered.  
  - The system either saves an empty draft or informs the author that there is no information to save.
- **4a**: A system error occurs while saving.  
  - The system notifies the author that the draft could not be saved.

---

## Fully Dressed Scenario Narratives

### Main Success Scenario Narrative
An author is in the process of submitting a paper and decides not to complete the submission immediately. After entering partial information into the submission form, the author selects the **Save** option. The system validates the entered information, stores the submission as a draft, and confirms that the draft has been saved. The author can later retrieve and complete the draft submission.

### Alternative Scenario: Invalid Entered Information
If the author enters information that violates validation rules, such as an improperly formatted email address, the system detects the issue during validation. The system displays an error message and prevents the draft from being saved until the invalid information is corrected.

### Alternative Scenario: No Information Entered
If the author attempts to save the submission without entering any information, the system detects that no data has been provided. The system either saves an empty draft or informs the author that there is no information to save, depending on system rules.

### Alternative Scenario: System Error During Save
If a system error occurs while saving the draft, the system notifies the author that the draft could not be saved and logs the error for administrative review.

## Acceptance Test Suite — UC-05

### AT-UC05-001 — Save Draft with Partial Information
**Preconditions:** Author is logged in and on submission form.  
**Steps:**  
1. Enter partial metadata  
2. Click **Save**  

**Expected Results:**  
- Draft is saved  
- Confirmation message displayed  

---

### AT-UC05-002 — Update Existing Draft
**Preconditions:** Draft already exists.  
**Steps:**  
1. Open saved draft  
2. Modify information  
3. Click **Save**  

**Expected Results:**  
- Draft updated  
- No duplicate draft created  

---

### AT-UC05-003 — Invalid Information Blocks Save
**Preconditions:** Author on submission form.  
**Steps:**  
1. Enter invalid data  
2. Click **Save**  

**Expected Results:**  
- Validation error displayed  
- Draft not saved  

---

### AT-UC05-004 — Save with No Information Entered
**Preconditions:** Author on new submission form.  
**Steps:**  
1. Enter no data  
2. Click **Save**  

**Expected Results:**  
- System behavior follows defined rule (empty draft saved or warning shown)  

---

### AT-UC05-005 — Draft Is Not Marked as Submitted
**Preconditions:** Draft exists.  
**Steps:**  
1. View submissions list  

**Expected Results:**  
- Draft labeled as **Draft**  
- Not included in submitted papers  

---

### AT-UC05-006 — System Error During Save
**Preconditions:** Backend failure simulated.  
**Steps:**  
1. Enter partial data  
2. Click **Save**  

**Expected Results:**  
- Error message displayed  
- Draft not saved  

---

### AT-UC05-007 — Retry Save After Failure
**Preconditions:** Previous save failed.  
**Steps:**  
1. Retry **Save** after system recovery  

**Expected Results:**  
- Draft saved successfully
